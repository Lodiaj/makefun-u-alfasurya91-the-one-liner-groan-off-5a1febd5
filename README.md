## The joke

> I asked my dog what's two minus two. He said nothing.

A dad asks his dog a maths question, and the dog's silence does double duty: it is the punchline and the correct answer at the same time (two minus two is nothing). Short, easy to say out loud, and the groan arrives the moment you realise the dog never said a word.

## How it works

`main.ts` (Node 22, TypeScript run as-is) checks the joke (1–140 characters, not only whitespace, one line) and writes it to `/output/entry.txt`. Run it with:

```sh
node main.ts
```

`OUTPUT_DIR` overrides the output directory (defaults to `/output`).
